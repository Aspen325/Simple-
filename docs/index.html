Home WiFi browser lab

Run Chromium outside your home network and use it in a private browser tab.

  1. Create a codespace with two cores, or resume your existing one.
  2. In the codespace terminal, run this command. The first start downloads the browser. 
    bash browser-lab/start.sh
  3. Open the editor's Ports panel. Forward port 3000 if missing, keep visibility Private, then choose Open in Browser. Type the test address into the remote Chromium address bar.
  4. Compare the result with an ordinary tab and check your router logs. Stop the codespace from the Codespaces dashboard when done.
